CloudPayments Kazakhstan Integration for Odoo 17

Description

This module is designed to integrate CloudPayments Kazakhstan with Odoo 17.
It allows online payments via CloudPayments, processes transaction statuses, and automates payment confirmation.

Key Features

  • Accept payments via CloudPayments
  • Handle payment status notifications
  • Automatically update transactions in Odoo
  • Configurable payment methods in Odoo

Installation

Copy the module to the addons/ directory of Odoo:


cd /odoo/custom/addons
git clone https://github.com/sakenever137/payment_cloudpayments.git
